Servicio de traducción

La extensión usa por defecto un endpoint compatible con LibreTranslate en fairtranslate.eu. Si ese servicio no te encaja o deja de responder, configura aquí tu instancia propia o la de otro proveedor compatible. También puedes probar MyMemory con el preset rápido, aunque suele ir mejor para frases cortas y tiene límites más estrictos. Si eliges DeepL, recuerda que necesitas una API key y que para uso serio conviene no exponerla en código cliente distribuido. Word Wise solo se aplica a texto detectado como alemán. Los sinónimos suelen encajar mejor con palabras sueltas, los ejemplos usan el idioma origen detectado o seleccionado y la pronunciación se reproduce con la voz disponible en el navegador.
